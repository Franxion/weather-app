# Note on the Use of AI

This note has two parts. Part 1 is the supplier's statement of 5 November 2026, unchanged. Part 2 was added by the client team, Group 17, on 10 November 2026, after the hand-over.

## Part 1: Supplier's statement (5 November 2026)

### 1. Tools Used

I used only one AI tool: **Claude Code**, an assistant by Anthropic that works directly on the project files from the terminal.

### 2. Purpose

I used Claude Code for two tasks:

- **Testing the application**: trying the quiz to check that it worked as expected.
- **Reviewing the code**: rereading the code I had written to look for errors (bugs) and to check that I had reached the goals of the project.

### 3. How I Verified the Result

- I asked Claude Code to check that the code did what I wanted it to do.
- I asked Claude Code to look for possible bugs.
- I read the issues it reported and I decided myself which changes to make.

### 4. Responsibility

The project and the final decisions are mine. The AI was used as support for checking my work, not to replace it.

## Part 2: Added by Group 17 (10 November 2026)

### Supplier, by milestone

The supplier declared one tool, Claude Code, for testing and code review, and no other AI use. The statement does not say which milestone it refers to.

- **Milestone 1:** quiz pages and logic, questions loaded from the JSON, accessibility fixes.

The logo and the three scenario illustrations in `assets/` come from Group 17's design mock-ups of 28 October 2026 (same shapes and colours). The mock-ups were made with an AI design tool and combined with Claude (Anthropic).

### Quiz content

The questions, answers, explanations, summaries and sources in `data/questions.json` were written by Group 17 with Claude (Anthropic), based on the official pages linked in each question, and checked against those pages. The file is byte-identical to the version the team handed over on 28 October 2026 (checked on 10 November 2026), so no safety text was changed during development, with or without AI.
